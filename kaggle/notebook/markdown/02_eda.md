# Section 2: Exploratory Data Analysis (EDA)

## Planned EDA Visualizations
1. **Class Distribution**: Severe class imbalance (~0.1% fraud label).
2. **Monetary Analysis**: Distribution of `amount` vs `spending_deviation_score`.
3. **Temporal Heatmaps**: Transaction frequency by `hour` and `day_of_week`.
4. **Graph Dynamics**: Fraud rates on cross-bank (`is_cross_bank_transfer`) vs cross-currency (`is_cross_currency_transfer`) transfers.
