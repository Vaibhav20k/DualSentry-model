# Section 1: Introduction & Problem Statement

## Executive Summary
Financial institutions process millions of transaction events per day. Traditional batch rules fail to capture real-time behavioral shifts in transaction velocity, sudden deviations from historical spending habits, or suspicious emerging payment networks.

This notebook demonstrates an end-to-end production workflow for Anti-Money Laundering (AML) anomaly detection using stateful behavioral feature engineering on the IBM AML synthetic dataset.

## Core Objectives
- Evaluate 15 stateful behavioral features generated by `FeaturePipeline`.
- Benchmark baseline anomaly detection algorithms (Isolation Forest, XGBoost).
- Target metrics: PR-AUC, F1-Score, False Positive Rate @ 99% Recall.
